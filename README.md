# DISTRICT SHOP

Фронтенд интернет-магазина оригинальных уличных кроссовок и стритвира.

## Страницы
- `index.html` — главная страница
- `catalog.html` — каталог с фильтрами
- `product.html` — карточка товара

## Возможности
- Фильтры по бренду, категории, полу, размеру, цене
- Поиск и сортировка
- Корзина и избранное (localStorage)
- Адаптивная вёрстка

## Запуск
Открой `index.html` в браузере или запусти локальный сервер:

```bash
npx serve .
```
